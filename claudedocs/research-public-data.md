## 1. 건강보험심사평가원 (HIRA) 공공데이터

HIRA는 보건의료빅데이터개방시스템(https://opendata.hira.or.kr)과 공공데이터포털(https://www.data.go.kr)을 통해 Open API를 제공한다.

### 공통 사항

| 항목 | 내용 |
|------|------|
| **인증 방식** | 공공데이터포털(data.go.kr) 회원가입 후 API 활용 신청 -> 서비스키(ServiceKey) 발급 |
| **비용** | 무료 |
| **데이터 형식** | XML (기본), 일부 API는 JSON 지원 (`_type=json` 파라미터) |
| **호출 제한** | 개발계정 일 1,000~10,000건 / 운영계정 활용사례 등록 시 증량 가능 |
| **승인** | 자동승인 (개발/운영 모두) |

---

### 1.1 병원정보서비스 (HospInfoService)

병원 기본 정보를 검색/조회하는 핵심 API.

| 항목 | 내용 |
|------|------|
| **공공데이터포털** | https://www.data.go.kr/data/15001698/openapi.do |
| **Base URL** | `https://apis.data.go.kr/B551182/hospInfoServicev2` |
| **주요 엔드포인트** | `GET /getHospBasisList` |
| **데이터 형식** | XML (기본) |
| **갱신 주기** | 실시간 |

#### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | O | 공공데이터포털 인증키 |
| `pageNo` | X | 페이지 번호 |
| `numOfRows` | X | 한 페이지 결과 수 |
| `yadmNm` | X | 병원명 |
| `sidoCd` | X | 시도코드 |
| `sgguCd` | X | 시군구코드 |
| `emdongNm` | X | 읍면동명 |
| `dgsbjtCd` | X | 진료과목코드 |
| `xPos` | X | x좌표(경도) |
| `yPos` | X | y좌표(위도) |
| `radius` | X | 반경(m) |
| `clCd` | X | 종별코드 |

#### 응답 필드

| 필드명 | 설명 |
|--------|------|
| `yadmNm` | 병원명 |
| `addr` | 주소 |
| `postNo` | 우편번호 |
| `telno` | 전화번호 |
| `hospUrl` | 홈페이지 URL |
| `estbDd` | 개설일자 |
| `sidoCd` / `sidoCdNm` | 시도코드 / 시도명 |
| `sgguCd` / `sgguCdNm` | 시군구코드 / 시군구명 |
| `emdongNm` | 읍면동명 |
| `clCd` / `clCdNm` | 종별코드 / 종별코드명 (상급종합, 종합병원, 병원, 의원 등) |
| `ykiho` | 암호화된 요양기호 (타 API 연계 키) |
| `XPos` / `YPos` | x/y 좌표 |
| `drTotCnt` | **의사 총수** |
| `mdeptGdrCnt` | 의과 일반의 수 |
| `mdeptIntnCnt` | 의과 인턴 수 |
| `mdeptResdntCnt` | 의과 레지던트 수 |
| `mdeptSdrCnt` | **의과 전문의 수** |
| `detyGdrCnt` / `detySdrCnt` | 치과 일반의/전문의 수 |
| `cmdcGdrCnt` / `cmdcSdrCnt` | 한방 일반의/전문의 수 |
| `pnursCnt` | 조산사 수 |

> **"양심 병원" 활용**: 의사 총수(`drTotCnt`), 전문의 비율 계산 가능

### 1.2 의료기관별 상세정보서비스 (MadmDtlInfoService)

의료기관의 시설, 진료과목, 장비, 간호등급 등 상세 정보.

| 항목 | 내용 |
|------|------|
| **공공데이터포털** | https://www.data.go.kr/data/15001699/openapi.do |
| **Base URL** | `https://apis.data.go.kr/B551182/MadmDtlInfoService2.7` |
| **데이터 형식** | XML, JSON (`_type=json`) |
| **갱신 주기** | 실시간 |

#### 엔드포인트별 정보

| 엔드포인트 | 조회 내용 |
|-----------|----------|
| `/getEqpInfo2.7` | **시설정보** - 병상수, 장비, 주소, 개설일자 |
| `/getDtlInfo2.7` | **세부정보** |
| `/getDgsbjtInfo2.7` | **진료과목정보** - 과목코드, 의사수, 선택진료 의사수 |
| `/getTrnsprtInfo2.7` | **교통정보** |
| `/getMedOftInfo2.7` | **의료장비정보** - 장비코드명, 보유 대수 |

#### 추가 제공 정보

- **간호등급정보**: 입원 환자 대비 간호사 비율 등급
- **식대가산정보**: 식이 서비스 수준
- **특수진료정보**: 특수 진료 분야
- **전문병원지정분야**: 보건복지부 전문병원 지정 여부
- **기타인력수**: 의료기관 인력 현황

#### 요청 파라미터 (공통)

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | O | 인증키 |
| `ykiho` | O | 암호화된 요양기호 (병원정보서비스에서 획득) |
| `pageNo` | X | 페이지 번호 |
| `numOfRows` | X | 한 페이지 결과 수 |
| `_type` | X | 응답 형식 (xml/json) |

> **"양심 병원" 활용**: 간호등급, 전문의 수, 의료장비 보유 현황, 전문병원 지정 여부

### 1.3 병원평가정보서비스 (HospAsmInfoService) - 핵심 API

의료 질 평가(적정성 평가) 결과를 조회하는 API. **"양심 병원" 판별의 핵심 데이터.**

| 항목 | 내용 |
|------|------|
| **공공데이터포털** | https://www.data.go.kr/data/15094093/openapi.do |
| **엔드포인트** | `https://apis.data.go.kr/B551182/hospAsmInfoService1/getHospAsmInfo1` |
| **데이터 형식** | XML |
| **갱신 주기** | 실시간 |
| **비용** | 무료 |

#### 요청 파라미터

| 파라미터 | 필수 | 설명 |
|---------|------|------|
| `serviceKey` | O | 인증키 |
| `pageNo` | O | 페이지 번호 |
| `numOfRows` | O | 한 페이지 결과 수 |
| `ykiho` | X | 암호화된 요양기호 |

#### 평가 항목 (asmNm)

| 평가 항목 | "양심 병원" 관련성 |
|----------|----------------|
| **급성상기도감염 항생제 처방률** | 핵심 - 감기에 항생제 남용 여부 |
| **급성하기도감염 항생제 처방률** | 핵심 - 하기도 감염 항생제 남용 |
| **주사제 처방률** | 핵심 - 불필요한 주사 처방 여부 |
| **약품목수(다약제)** | 핵심 - 과다 처방 여부 |
| 급성심근경색 | 치료 질 지표 |
| 급성뇌졸중 | 치료 질 지표 |
| 혈액투석 | 치료 질 지표 |
| 관상동맥우회술 | 수술 질 지표 |
| 고혈압/당뇨 관리 | 만성질환 관리 질 |
| 천식/COPD/폐렴 | 호흡기 치료 질 |
| 대장암/위암/유방암/폐암 | 암 치료 질 |
| 중환자실/신생아중환자실 | 중환자 치료 질 |
| 요양병원 | 장기요양 질 |
| 의료급여 정신과 | 정신건강 치료 질 |

#### 등급 체계

- **1~5등급** (백분위 순위 기반)
- **숫자가 작을수록 우수** (1등급 = 가장 적절한 처방)
- 진료건수 100건 미만 기관은 평가 제외

## 4. "양심 병원" 판별 활용 지표 종합

### 핵심 지표 (직접 API 조회 가능)

| 지표 | 데이터 소스 | API |
|------|-----------|-----|

| **항생제 처방률 (하기도)** | HIRA 병원평가정보 | hospAsmInfoService1 |
| **주사제 처방률** | HIRA 병원평가정보 | hospAsmInfoService1 |
| **약품목수 (다약제)** | HIRA 병원평가정보 | hospAsmInfoService1 |

### 보조 지표

| 지표 | 데이터 소스 | API |
|------|-----------|-----|
| 전문의 비율 | HIRA 병원정보 | hospInfoServicev2 |
| 간호등급 | HIRA 의료기관상세정보 | MadmDtlInfoService2.7 |
| 의료장비 보유 현황 | HIRA 의료기관상세정보 | MadmDtlInfoService2.7 |
| 전문병원 지정 여부 | HIRA 의료기관상세정보 | MadmDtlInfoService2.7 |
| 병상수 | HIRA 의료기관상세정보 | MadmDtlInfoService2.7 |
| 수술/질병별 치료 질 등급 | HIRA 병원평가정보 | hospAsmInfoService1 |

### "양심 병원" 점수 산정 제안 로직

```
양심 점수 =
  (항생제 처방률 등급 점수 x 가중치) +
  (주사제 처방률 등급 점수 x 가중치) +
  (약품목수 등급 점수 x 가중치) +
  (우수기관 연속 선정 보너스) +
  (전문의 비율 보너스) +
  (간호등급 보너스)
```

등급 점수: 1등급=5점, 2등급=4점, 3등급=3점, 4등급=2점, 5등급=1점

## 5. API 연계 흐름

```
1. 병원정보서비스 (hospInfoServicev2)
   └─ 병원 검색 (이름, 지역, 진료과목)
   └─ ykiho (암호화된 요양기호) 획득
       │
       ├─ 2. 의료기관상세정보 (MadmDtlInfoService2.7)
       │      └─ 진료과목, 의료장비, 간호등급 조회
       │
       ├─ 3. 병원평가정보 (hospAsmInfoService1)
       │      └─ 항생제/주사제 처방률, 치료 질 등급
       │
       └─ 4. 우수기관평가정보 (exclInstHospAsmInfoService1)
              └─ 우수 기관 선정 이력
```

> **중요**: `ykiho`(암호화된 요양기호)가 모든 API를 연결하는 공통 키 역할을 한다. 병원정보서비스에서 먼저 `ykiho`를 획득한 후 다른 API에 전달하여 상세 정보를 조회하는 구조이다.
