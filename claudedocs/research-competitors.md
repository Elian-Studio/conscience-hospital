|------|------|
| 모바일 예약/접수 | 병원 EMR 시스템과 직접 연동된 유일한 모바일 접수 서비스 |
| 실시간 대기 확인 | 병원 방문 전 현재 진료 대기자 수 모바일 확인 |

- 모바일 접수 -> 대기순서 확인 -> 방문의 흐름에 최적화
- 지도 + 리스트 혼합형 (접수/예약 중심)

#### 비즈니스 모델
- **멤버십 구독**: 접수 기능 및 추가 혜택은 유료 멤버십 필요 (예약은 무료)

- **포인트 시스템**: 활동 포인트로 멤버십 무료 이용권 교환 가능

#### 강점/약점
- **강점**: EMR 연동으로 실제 접수 처리 가능, 대기시간 절감 효과 명확
- **약점**: 병원 추천/평가보다는 접수 편의성에 집중, 리뷰/평판 기능 미약

## 3. 경쟁 우위 분석

### 3.1 기존 서비스들의 공통 한계점

1. **광고 기반 추천의 신뢰성 문제**
   - 대부분의 서비스가 병원 광고료를 주요 수익원으로 함
   - 광고비를 많이 지불하는 병원이 상위 노출되는 구조
   - 사용자는 "추천"인지 "광고"인지 구분하기 어려움

2. **리뷰 신뢰성 이슈**
   - 병원이 환자에게 특정 내용의 리뷰를 강요하는 사례 존재
   - 홍보성 후기와 실제 후기 구분 어려움
   - 평점이 실제보다 높게 왜곡되는 현상
   - 보건복지부 적발: 자발적 후기를 가장한 불법 의료광고 366건 (2025)

3. **비급여/미용 시술 편중**
   - 수익성 높은 비급여 시술(성형, 피부, 안과, 치과)에 집중
   - 일반 내과, 소아과 등 기본 진료과에 대한 정보/추천 미흡
   - 수익 모델이 비급여 중개에 편중되어 공공성 부족

4. **"진짜 좋은 병원" 기준 부재**
   - 의료 품질, 과잉진료 여부, 적정 진료비 등 본질적 평가 없음
   - 접수 편의성, 시설, 친절함 등 부수적 요소 중심 평가
   - 건강보험심사평가원의 의료 질 평가 데이터 활용 미흡

5. **정보 비대칭 해소 미흡**
   - 비급여 진료비 비교는 일부 서비스에서 제공하지만 제한적
   - 과잉진료, 불필요한 시술 여부 판단 정보 부재
   - 의사의 전문성/경력 정보 부족

### 3.2 사용자가 느끼는 주요 불편점

1. 어떤 병원이 "진짜 실력 있는" 병원인지 알 수 없음
2. 과잉진료를 하는 병원인지 판단할 근거가 없음
3. 비급여 항목의 적정 가격을 알 수 없음
4. 리뷰가 광고인지 실제 후기인지 구분 어려움
5. 동네 의원급에 대한 정보가 특히 부족
6. "양심적으로 진료하는 병원"을 찾는 방법이 없음

### 3.3 "양심 병원" 서비스의 차별화 기회

| 차별점 | 설명 |
|--------|------|
| **과잉진료 필터링** | 건강보험심사평가원 데이터를 활용한 적정 진료 여부 평가 |
| **비급여 적정가격 제시** | 비급여 항목의 평균가/적정가 기준 제시 및 비교 |
| **의료 질 평가 통합** | 심평원 의료기관 평가 등급, 적정성 평가 결과 통합 |
| **광고 배제 추천** | 광고료가 아닌 의료 품질 기반 순수 추천 알고리즘 |
| **처방 패턴 분석** | 항생제 처방률, 주사제 처방률 등 객관적 데이터 활용 |
| **환자 중심 리뷰** | "과잉진료 없었는지", "설명을 충분히 해줬는지" 등 양심 관련 리뷰 항목 |
| **일반 진료과 강화** | 비급여 미용 시술이 아닌 내과, 소아과 등 일상 진료 중심 |

## 7. 핵심 인사이트 요약

### "양심 병원" 서비스가 노려야 할 포지셔닝

1. **"광고 없는 진짜 추천"** - 기존 서비스들의 가장 큰 약점인 광고 기반 추천을 정면으로 공략
2. **"공공 데이터 기반 객관적 평가"** - 심평원 평가, 비급여 적정가격, 처방 패턴 등 객관적 데이터 활용
3. **"일반 진료 특화"** - 성형/미용이 아닌 일상적 진료(내과, 소아과, 정형외과 등) 중심
4. **"과잉진료 감시"** - 불필요한 검사, 과도한 처방을 하지 않는 "양심적" 병원 식별
5. **"동네 의원 정보 강화"** - 대형 병원이 아닌 1차 의료기관(동네 의원)에 대한 풍부한 정보

### 진입 전략 제안

- **1단계**: 특정 지역 + 특정 진료과(내과, 소아과) 집중 -> 밀도 확보
- **2단계**: 공공 데이터(심평원) 통합으로 객관적 평가 체계 구축
- **3단계**: 커뮤니티 기반 "양심 리뷰" 시스템 (과잉진료, 설명 충분성 등 평가 항목)
- **4단계**: 지역 및 진료과 확장
